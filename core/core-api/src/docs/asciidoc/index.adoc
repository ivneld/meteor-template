== 개요

성공 응답은 리소스 표현을 그대로 내려준다.
오류 응답은 RFC 9457 Problem Details(`application/problem+json`) 형식이며 `code` 확장 속성으로 에러 코드를 전달한다.

== 오류 응답

=== 에러 코드

[cols="1,1,3"]
|===
| code | HTTP status | 설명

| C001 | 400 | 요청이 올바르지 않음 (검증 실패 포함, `errors` 속성에 필드별 오류)
| C002 | 404 | 리소스 없음
| C003 | 405 | 허용되지 않은 메서드
| C004 | 415 | 지원하지 않는 미디어 타입
| C999 | 500 | 서버 내부 오류
| S001 | 404 | 샘플 없음
| S002 | 409 | 이미 비활성화된 샘플
|===
